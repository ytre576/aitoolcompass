# 部署计划：推送到GitHub Pages

## 任务概述
将网站更新推送到GitHub仓库，触发GitHub Actions自动部署到生产环境。

## 部署配置
- **仓库地址**: https://github.com/ytre576/aitoolcompass.git
- **部署分支**: main
- **部署方式**: GitHub Actions自动部署
- **生产地址**: https://aitoolcompass.bbroot.com

## 执行步骤

### 步骤1：添加所有文件到暂存区
```bash
git add .
```
**预期结果**: 所有修改和新增文件被添加到暂存区

### 步骤2：创建提交
```bash
git commit -m "feat: 批量添加105篇AI工具文章，文章总数达到215篇

- 新增105篇AI工具评测、教程、对比文章
- 涵盖chatbots、research、image、video、design、productivity、writing、coding、audio共9个分类
- 为每篇文章创建对应的SVG配图
- 更新首页统计数字
- 删除多余的SVG文件
- 更新站点配置和分类页面"
```
**预期结果**: 创建一个包含所有更改的提交

### 步骤3：推送到远程仓库
```bash
git push origin main
```
**预期结果**: 代码推送到GitHub，触发GitHub Actions自动部署

### 步骤4：验证部署
- 检查GitHub Actions工作流状态
- 访问 https://aitoolcompass.bbroot.com 验证部署结果

## 关键文件

### 配置文件
- `.github/workflows/pages.yml` - GitHub Actions部署配置
- `data/site-config.json` - 站点配置
- `data/custom-articles.json` - 自定义文章数据

### 内容文件
- `index.html` - 首页
- `articles/` - 215篇文章HTML
- `assets/article-art/` - 215个SVG配图
- `categories/` - 10个分类页面

### 工具文件
- `tools/generate-site.js` - 站点生成器
- `tools/validate-site.js` - 站点验证器

## 验证方法

1. **提交验证**: 检查git status确认所有文件已提交
2. **推送验证**: 检查git log确认推送成功
3. **部署验证**: 访问生产地址验证网站更新
4. **功能验证**: 检查文章页面、分类页面、图片引用是否正常

## 回滚方案

如果部署失败，可以通过以下方式回滚：
1. 使用git revert回滚提交
2. 或手动触发GitHub Actions重新部署旧版本

## 注意事项

1. 部署过程可能需要2-3分钟
2. 部署期间网站可能暂时不可访问
3. 建议在低峰期进行部署
4. 部署后需要清除CDN缓存（如有）
